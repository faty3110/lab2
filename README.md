# Streamlit Data Applications - Competitor and Sentiment Analysis

## Overview
This project demonstrates two data applications using Streamlit:
1. **Competitor Analysis** - Visualizes key metrics and comparisons between different mobile apps.
2. **Sentiment Analysis** - Analyzes app reviews based on star ratings and categorizes them into Positive, Neutral, and Negative sentiments.

## Requirements
- Python 3.8 or higher
- Streamlit
- Plotly
- Pandas

## How to Run
1. Install the required packages:  
   `pip install streamlit plotly pandas`
2. Run the application:
   ```bash
   streamlit run competitor_analysis.py
   streamlit run sentiment_analysis.py
